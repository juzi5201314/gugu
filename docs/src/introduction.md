# Gugu

Gugu 是一门面向系统级性能的静态类型语言：表面语法接近脚本语言，编译之后的语义是闭世界、定布局、可单态化的机器码。

本书源目录是 `docs/src`。分工如下：

- [语言规范](spec/overview.md)（`spec/`）：规范性文本。实现必须符合这里写下的条款。概述章末有术语表。
- [教程](guide/getting-started.md)（`guide/`）：从入门到部署的使用指南，示例服从规范。
- [参考手册](reference/syntax-cheatsheet.md)（`reference/`）：语法、类型、标准库 API、CLI、诊断码等速查。
- [编译器内部](internals/bootstrap.md)（`internals/`）：实现说明，描述当前编译器与运行时的做法；不要把实现细节读成语言定义。
- 架构决策记录在仓库的 `docs/adr/`，不纳入本书导航。它们记录「为什么这样定」，规范只记录「语言是什么」。

规范里用「必须 / 禁止 / 可以」：必须与禁止是实现约束；可以是允许的实现或写法，不保证每一种都会出现在标准库里。
